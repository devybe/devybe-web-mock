# DeVybe web mock

1. Project: devybe-web-mock (already created, schema applied).
2. Project Settings → API → copy Project URL and anon public key into config.js.
3. Deploy this folder as a static site (Netlify Drop, Vercel, or GitHub Pages).

View data: Supabase → Table Editor → mock_participants / mock_place_vibes / mock_events.
Without keys in config.js the site runs in demo mode (saves in the browser only).
